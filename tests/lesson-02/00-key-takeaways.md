# Review Less 02
## 1. Giải thích các câu lệnh về git
1. **git init**: khởi tạo git, dùng để khởi tạo 1 thư mục Git chạy 1 lần cho lần đầu tiên
2. **git add**: add các mục cần lưu vào staging, chuẩn bị cho lần commit tiếp theo
3. git add . : add tất cả các file thay đổi trong project vào staging, chuẩn bị cho lần commit tiếp theo
4. git commit -m"messge": lưu các thay đổi của các file đã add với message rõ nghĩa
